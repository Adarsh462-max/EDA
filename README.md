# EDA
# Iris Dataset Exploratory Data Analysis

## Project Overview
This project performs Exploratory Data Analysis (EDA) on the Iris dataset using Python.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Dataset
The Iris dataset contains information about:
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width
- Species

## Tasks Performed
- Data Loading
- Data Cleaning
- Statistical Summary
- Data Visualization
- Correlation Analysis

## Results
- Setosa species is clearly separable.
- Petal dimensions are highly correlated.
- Dataset contains balanced classes.
